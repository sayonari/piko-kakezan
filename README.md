# ピコピコかけざん 🟪🟩

小学2年生むけ、**九九** を「ならべて・かぞえて・となえて」覚えるレトロゲーム。
iPhone / iPad の Safari でそのまま遊べます（インストール不要・オフライン対応）。

▶ **あそぶ: https://sayonari.github.io/piko-kakezan/**

姉妹作: [ピコピコたしざん](https://sayonari.github.io/piko-tashizan/)（2けたの たしざん）

## あそびかた
1. `7×8=?` のような問題が出て、盤面に **筆算** が組み上がります（数字が落ちてきて、線が引かれ、答えの箱が並ぶ）
   - 左の列＝十のくらい（オレンジ）、右の列＝一のくらい（青）。かけられる数はピンク、かける数はみどり
2. 正解すると… かけられる数とかける数が光り、**2本のビーム** が答えの場所で合体して **大爆発**！
   出てきた `56` が **5は十の箱へ・6は一の箱へ** わかれて飛びこみ、「しちは ごじゅうろく」がカラオケ風に出ます
3. **「ヒント!」** を押すと、筆算が左によって **九九のかいだん**（7×1=7 → 7×2=14 → …）が出ます。
   段のあいだの `+7` の矢印で「ひとつ上の答え ＋ 7 = つぎの答え」という関係が見えます（まちがえた時も自動で出ます）
4. 1回で正解すると金の★、まちがえた後だと銀の★。全部金なら 👑

| モード | 内容 |
|---|---|
| ○のだん | 教科書の順（2→5→3→4→6→7→8→9→1）。初回は ×1〜×9 の順番、クリア後はばらばら |
| ミックス | 2〜9のだんから10問 |
| タイムアタック | 60秒で何問とけるか。ベスト記録を保存 |
| 🌈🔥 のうじるモード | 30秒スタートのド派手コンボアタック。正解で+2びょう、10コンボで「フィーバー!!」 |
| 九九ひょう | 1回で正解した九九が表に集まっていく。マスをタッチすると唱え方を読み上げ |

数字の色は「十のくらい＝オレンジ」「一のくらい＝青」で、たしざんと共通です。

## メニュー（4つの へや）
さいしょの画面は、4さいでも えらべるように ★の数とアイコンで 分けています。
| へや | 中身 |
|---|---|
| ★ やさしい | きほんの れんしゅう |
| ★★ ふつう | すこし むずかしい れんしゅう |
| ★★★ むずかしい | しあげの れんしゅう |
| 🎮 ゲームで あそぶ | のうじるモード・はやおしバトル・じっくりバトル |

## ⚔️ たいせんモード（てき: スライム → コウモリ → おばけ → ロボット → ドラゴン → つよい○○ …）
- **⚡ はやおしバトル**: おなじ問題を てきと 早押し。てきの「かんがえちゅう…」ゲージが たまる前に正解すると こうげき！ 先に答えられると ハートが へる。まちがえるとゲージが進む
- **⚔️ じっくりバトル**（ターンせい）: 自分の番に **こうげき / かいふく / ひっさつ** をえらび、問題に正解すると成功（はやく正解すると「かいしんの いちげき」）。
  ひっさつは正解3回でたまる★を使う、むずかしい問題で大ダメージ。てきの番は「けいさんで まもれ!」→ 正解でガード。
  てきが「ちからを ためている!」ときは強いこうげきが来るので、かいふくするか考えよう
- 勝つと「つぎの てき」でレベルアップ。たおしたレベルは記録されます
- 対戦の仕組みは `battle.js`、メニューは `menu.js`（ピコピコたしざん／かけざん共通）

## 🌈🔥 のうじるモード
- 正解するたびに **レインボーの爆発・衝撃波・画面フラッシュ**、コンボが上がるほど効果音の音程がどんどん上がる
- 5コンボごとに点数の倍率アップ、正解で **+2びょう**、まちがえると **-3びょう** でコンボがとぎれる
- **10コンボで「フィーバー!!」**：画面全体がレインボーに回転、BGMがスピードアップ（20コンボ「すごすぎ!!」30コンボ「かみ!!!」）
- 演出は `fever.js`（ピコピコたしざんと共通）

## iPhone / iPad で遊ぶ
Safari で開き、共有ボタン →「ホーム画面に追加」で全画面アプリになります。マナーモードでも音が出ます（Safari 16.4 以降）。

## 技術メモ
- `index.html` 1ファイル（Canvas + WebAudio チップチューン + SpeechSynthesis）。エンジンは piko-tashizan と共通
- `sw.js` でオフラインキャッシュ、進行状況は localStorage
- アイコン再生成: `uv run --with pillow make_icons.py`
